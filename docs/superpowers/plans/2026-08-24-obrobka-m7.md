# obrobka M7 — пензель: план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ручна правка маски пензлем — стерти зайве, повернути з'їдене.

**Architecture:** одна чиста операція ядра `paint`, що править альфу за
двома масками мазків, плюс режим малювання у наявному `Stage.svelte`.
Жодної нової моделі й жодного завантаження.

**Tech Stack:** TypeScript 7, Svelte 5, Astro 7, Vitest 4, Playwright 1.62.

## Global Constraints

- Специфікація: `docs/superpowers/specs/2026-08-24-obrobka-m7-design.md`.
- Ядро без DOM і без Node API.
- Коментарі й назви тестів — українською.
- Словники uk та en мають однакові ключі; в англійському немає кирилиці;
  у Svelte-компонентах немає вшитих рядків — це перевіряє `i18n.test.ts`.
- Кожен стиль компонента має доходити до збірки — перевіряє `build.test.ts`.
- Маски мазків зберігаються зменшеними до **1024 px** по більшій стороні.
- `paint` іде **одразу після `removeBackground`**, до `outline` і решти.
- Дані в Job — звичайні об'єкти, не проксі Svelte (див. `plainLayer`).
- Після кожної задачі: `pnpm typecheck` і `pnpm test`.

## Task 5: режим малювання у `Stage.svelte`

**Files:** `apps/web/src/components/Stage.svelte`

**Interfaces:**
- Нові пропси: `brush?: { on: boolean; mode: 'erase' | 'restore'; size: number }`,

- [ ] **Step 3:** `onstroke` кличеться **на `pointerup`**, не щокадру.
- [ ] **Step 4:** тягнення кадру в режимі пензля вимкнене; шар теж не рухається.
